V1 的三网配置、导入冲突和其他失败分支完整保留；本轮没有把每个 V1 画板全部精修为 v2。新稿各边读取后核对目的地，不能把 91 条边称为 91 条手动点击通过。

共享 JSON 中原有 48 个 live token 与工程别名分开记录；另 5 个深色文字 token 保存于 Penpot v2 token set（共 53 项）。控件白字与靛蓝品牌色保留。组合字形、中文 IME、字体列宽与性能继续由验证壳实测。

实际 Chrome 预览点击核验：S01→S13→S05→S12→S10，以及直接打开 S08 后 S08→S09→显式核实→S03。每一步核对 viewer current-frame；见 [点击记录](evidence/v2-viewer-smoke.json)。临时预览页已关闭，保留原编辑页。

独立 ADR-0007 复核后的精准更正：S13 示意输出改为“生成本次请求绑定的响应码后退出”。一次性 helper 的生命周期不代表二维码天然只能扫描一次；响应仍需请求绑定、有效期及重放防护的实现验证。见 [单对象修改读回](evidence/v2-request-binding-correction.json) 与 [S13 图片](evidence/v2-S13.png)。
