# 路线图

> 2026-10-30 执行增补：核心 Penpot 原型、两路线验证壳与云构建已推进，macOS 有有限原生 smoke；当前不足以锁定框架。真实结果、构建失败、15格单网络与20格并发矩阵见[验证记录](09-prototype-validation.md)。下文保留原评估／里程碑规则。

后续执行仍以手机为第一验收对象：在 v2 两壳上先推进[手动审查到远端只读快照](12-mobile-remote-readonly.md)，Android／iOS 构建优先排队，桌面保持同一矩阵。此小步不代替扫码、安全存储、持续终端、远端输入或手机设备验收，也不提前勾选整个 M1。

里程碑基线：2026-10-29，当时只有设计文档；2026-10-30已进入验证壳阶段，进度以上方执行记录为准。里程碑以可复现证据验收，不以代码量或功能勾选替代结果。

**首版目标是五端统一产品，手机优先、桌面紧随，三网络全部纳入设计与集成**：App 内 Tailscale + EasyTier 为首版必需，ZeroTier 并行验证与集成。按手机终端 A/B → 统一基础与五端验证 → 直连闭环 → provider × 平台接入 → 公开发布矩阵推进；Windows 原生桥风险同步做最小验证。范围见[产品设计](05-product-design.md)，实现契约见[架构](02-architecture.md)及 [ADR-0004](adr/0004-mvp-reliability-boundaries.md)。

面向 herdr 用户公开开源，已确定希望衍生改动继续开源，具体许可证经依赖审查后选定。五端首版均须支持完整交互终端，手机增加任务入口与输入辅助。小范围试用只作为预发布阶段；可先发布标清平台限制的预览版，M0.5–M3 五端全通过前不宣称五端同能力。首版只通过 SSH 连接远端 herdr，本机已有会话后置；不做 local socket 入口、安装启动或本地 shell/daemon/WSL 管理。

首版已确定前台跨 provider 同时连接、多终端标签（手机切换、桌面分屏），并采用源码与测试渠道先行、逐步正式上架的节奏；这些是验收要求，不再是待答选项。

首版还须支持手机扫码配对（手动兜底）、五端本地配置与偏好的加密导入导出；后台通知后置，先提供前台状态，不引入云账号或自动同步。

**云端 CI 构建优先、本地轻量**也是已定方向。SDK/NDK、Xcode、Visual Studio、Rust/Go 等重型工具默认由 runner 提供，本地以编辑器、Git、下载测试包与设备验收为主，调试工具按需选用；保留可选本地重建路径。2026-10-29规划时尚无App工作流；现有测试构建与有限Mac运行见执行记录，尚非正式客户端。本轮不安装完整SDK或清理既有工具。边界见[构建与发布](07-build-and-release.md)。

## M0.5 · 手机终端 A/B 与五端可行性验证

先用最小终端验证壳比较 Flutter 与 Tauri 2 + xterm.js + Rust，优先在云端生成测试包，再采用相同 iOS/Android 真机和 fixture，**正确性通过后才比较性能**，不开发两套完整客户端。共享协议、连接、状态与输入契约保持框架中立，Windows 原生桥与许可核查并行；其他平台随后按同一门槛验证。候选依据见[技术评估](06-technology-evaluation.md)，所有操作只针对独立测试目标。

并行按 [UI 设计交付计划](08-ui-design-plan.md)制作 Penpot 低/中保真可点击原型，覆盖扫码双端授权、完整终端三模式、跨网多标签与恢复，以及导入冲突和桌面分屏。真机结果回流后定稿关键页和组件；不等五端全量像素稿才开始技术验证，原型也不替代 IME、字体、网络与性能证据。

| 验证 | 最小产物与通过条件 | 阻断条件 |
| --- | --- | --- |
| 云端构建与产物分层 | 固定源码/工具链的五端 GUI 构建、自动化检查与候选测试包；三网 native 基础产物、helper 的 Unix 主机 OS/CPU 矩阵独立记录。 | 只有编译结果而无可安装测试路径，来源/许可材料缺失，或用 GUI 五端成功替代 helper/native 验证。 |
| 手机终端 A/B（先行关口） | 相同逐键/快捷键/交互 TUI、辅助输入、触控滚动/选择、IME、粘贴、Nerd Font/ANSI、焦点、生命周期与恢复 fixture；记录两候选的通过/失败/未知，再比较合格者性能和原生集成成本。 | 仅能草稿发送、完整终端不可用，或输入错误、光标/字形错位、丢帧后不能恢复，不能被吞吐或桌面表现抵消；未测不算胜出。 |

| 五端构建与终端输入 | 移动真机与桌面目标系统运行；验证完整逐键终端、交互 TUI、IME、键盘焦点、粘贴、窗口/转屏、Nerd Font 字形/列宽及帧显示，固定设备、负载与性能预算。 | 构建通过但无法运行，完整交互缺失、输入内容错误、字形/光标列错位，或组件无法达到预算。 |

| 手机配对与配置迁移 | 核实无桌面 GUI 的扫码路径、配对凭据生命周期、五端加密配置审查导入及秘密分类。 | 扫码隐含主机授权/自动信任、导入即连接、复制设备私钥/节点身份，或畸形包部分写入。 |

- [ ] 固定 A/B 候选、SSH、终端和原生依赖版本及构建方式；云端构建、自动化、签名、分发、设备运行各记结果，依据实测选择框架，不将第一候选当定案。
- [ ] native 基础产物以源提交/补丁/工具链和目标平台关联，再供 GUI 集成；helper 独立编译与测试，不依赖桌面 GUI 或主机安装 GUI SDK。可选本地重建使用同一锁定材料。
- [ ] 将五端完整终端及手机辅助层列为首版必测；快捷键/组合键、草稿、多行粘贴预览采用默认设计，记录用户确认的目标与实现者选择的控件，不用辅助层代替完整终端。
- [ ] 核实绑定的进程级节点限制、状态存储与系统版本要求，确定实际支持范围。
- [ ] 三网络使用独立配置与秘密范围，建立共享节点释放规则；单网验证与首版必需的跨 provider 并发分开记录，至少验证 Tailscale + EasyTier，不扩成同 provider 任意多身份。
- [ ] 手机标签切换、桌面分屏验证独立目标/草稿、输入焦点和资源预算；隐藏标签可暂停观察/渲染并在新 full 后恢复，分屏调整不静默 resize 远端。
- [ ] 分清断开主机、离开网络/停用配置、删除身份的实际效果，不将停用统一解释为销毁原生节点；重叠地址须证明底层可定向到选定网络，否则拒绝该并发组合并改用显式切换。
- [ ] 与手机 A/B 并行做 Windows overlay 原生桥最小验证：当前 Dart 候选 `tailscale` 0.9.0 不支持 Windows，不能靠 UI 框架可构建跳过；Linux 验证系统凭据服务缺失/锁定时的行为，不回退明文。
- [ ] 按衍生改动继续开源的立场核清候选组件许可与分发条件，再用相同五端 IME、ANSI 与性能用例比较；通过前不锁定组件，也不把项目开源立场直接当作某个 GPL/AGPL 许可证已选定。
- [ ] 字体是终端选型必过项：固定纯 zsh、选定 Oh My Zsh 主题/Powerlevel10k、Oh My Posh 图标配置的五端 fixture，覆盖 Powerline/Git/PUA/CJK/emoji/组合字符、IME、光标列、换行、本地字号/观察视图 resize 与异步重绘；不接管远端 PTY，锁定字体版本与可再分发许可。
- [ ] 固定共享 SSH 字节流与取消/关闭契约，原生差异留在平台适配层，不复制整套业务核心。
- [ ] 留存可重跑步骤，分别记录通过、失败与未执行项。

最低系统版本、CPU 架构、性能预算和依赖版本在此阶段确定。手机优先决定验证顺序，不取消桌面目标或推迟已知原生桥阻断项。[支持矩阵](05-product-design.md#8-五端支持与开源发布)分别记录基础平台能力、15 个单网络组合及额外并发能力，不根据框架、Heeler 或某一 wrapper 的能力直接宣布本项目支持。

## M1 · 扫码与手动接入的前台闭环

先在已知可达的 SSH 路径上完成“查看 → 定位 → 输入 → 核实反馈”。

- [ ] 手机扫码添加主机，手动配置兜底；提供不依赖本项目桌面 GUI 的配对入口，预览配置、明确授权、核对指纹后主动连接与诊断。
- [ ] 将已审阅的关键流程、状态/禁用理由和组件标注映射到产品验收，随对应功能实现核对真机行为；设计交付见 [UI 计划](08-ui-design-plan.md)。
- [ ] 实现一次性主机辅助命令：展示账号/公钥指纹，主机用户确认后添加手机专属公钥并退出；提供仅清理本次新增授权项的撤销方式，不宣称撤权会断开现有 SSH。经已有可信渠道或手工传公钥，不新增监听、常驻服务或同一 LAN 前提。
- [ ] 区分可复用资料码与配对请求/响应，验证后者过期、错配与重复完成；保留“已授权、尚未验证”状态，码到期不当作主机撤权，静态码不冒充一次性授权。
- [ ] 五端本地配置/偏好加密导出与审查导入；预览覆盖/冲突/缺失认证项及受影响连接/标签，替换在用配置时停止相关连接与自动重试；按秘密分类排除设备私钥和节点身份，不自动连接/信任/发送。
- [ ] 按主机分组的看板、待处理项、同步时间与失去连接状态。
- [ ] 手机看板进入多个终端标签并切换；桌面主机侧栏、列表与多标签/分屏工作台，支持窗口调整和键盘导航，始终只有一个明确输入焦点。
- [ ] 从看板进入准确目标，观察终端，区分当前画面与旧画面。
- [ ] 五端默认观察，显式进入完整逐键终端，支持快捷键、组合键与交互 TUI；手机提供辅助键、草稿编辑和多行粘贴预览。
- [ ] 区分明确成功、明确失败与发送结果待核实；禁止离线排队和自动重放。
- [ ] 重连后重新同步状态与全量画面；目标退出或身份变化时关闭发送。
- [ ] 本地凭据安全保存与删除入口，诊断日志脱敏。

验收：手机新用户无需桌面 GUI 也能扫码接入，畸形资料与错配/过期/已完成响应被拒，手动兜底可用；扫码后所需入网/授权步骤明确，实际 SSH 认证成功才计配对完成。五端加密迁移在错误口令/篡改/冲突下不部分导入或自动信任。再通过首连、逐键/TUI、草稿/粘贴、多标签、模式切换、目标变化和恢复；手机辅助与桌面分屏不串目标。保存实际输入及反馈，证明主机、session、目标和内容一致。逐键中断不积压，未知不重放；未通过的平台记录实验或未支持。

阻断条件：可绕过指纹核验、可能向错误目标发送、自动重复输入，或无法标明旧画面与未知发送结果。受影响平台不能进入日常使用预发布。

## M2 · 按 provider × 平台集成三网络

Tailscale、EasyTier 和 ZeroTier 分别推进，共用 M1 的可信连接与输入流程。正式核心平台须通过 Tailscale + EasyTier 单网及二者前台并发；声明 ZeroTier 支持还须通过 Tailscale + ZeroTier、EasyTier + ZeroTier 和三者同开，技术/许可未验证前不宣布支持。跨 provider 并发不等于同 provider 任意多身份/多实例，也不承诺后台常连。

- [ ] 手工创建各类型网络配置、接入、身份保存、重启/退出与分层状态提示；敏感配置不进入普通诊断。
- [ ] Host 候选路径引用网络配置，同一配置供多主机复用；停止单个主机不停止共享节点。
- [ ] 仅用已配置/可用网络发起有界连接尝试，待认证配置显示需操作；验证可信主机选择、重叠地址隔离与落败连接清理。
- [ ] 验证显式切换、停用配置、节点退出与认证失效；展示受影响主机，恢复前关闭输入，退出后不静默重试。
- [ ] 每个已支持单网组合通过身份/秘密隔离、共享节点复用与释放用例；前台 TS+ET 同时连接不同主机并输入，停用一网不影响另一网；声明 ZeroTier 支持须另过 TS+ZT、ET+ZT 及三者同开。

验收：无公开入站路径的测试主机上，各 provider × 平台在对应系统网络客户端关闭时完成看板、终端与输入闭环。分别记录平台/库版本、网络条件、连接路径、恢复及清理证据；不能用一个组合成功代替其余 14 格。

阻断条件：依赖系统 VPN 才成功、泄漏资源、串用网络秘密/路由、退出后恢复旧身份，或未通过完整流程。对应组合保持实验/未支持，不能以 LAN 演示、另一 provider 或逐网切换冒充并发通过。

本机已有 herdr 会话接入、文件、Git diff、会话历史、结构化输入辅助、独立多窗口与更完整的更新体系，分别定义范围、依赖和验收后再排期。多标签和桌面分屏已在首版，不放入这里。本机接入不自动扩展为安装或进程管理；三网络集成与前台跨 provider 并发仍在 M0.5/M2/M3 推进，不能因难度大后置；审批按钮先等待可靠的上游契约。

旧版“5–8 周自用可用”等数字未经原型校准，不作为交付承诺。M0.5 完成后，根据真实集成难度、支持范围与投入重新估算 M1–M3；M4/M5 独立排期。局部通过可以记录，但只有满足验收和依赖条件才标记里程碑完成。
