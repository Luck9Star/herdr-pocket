# 首版产品设计

设计基线：2026-10-29。本文定义待实现的产品，2026-10-30已进入核心原型与并行验证壳阶段，实际进度见[验证记录](09-prototype-validation.md)。产品面向 herdr 用户公开开源，用户希望衍生改动继续开源；具体许可证须经依赖兼容性审查后确定。小范围试用是预发布验证阶段，不再是产品定位。

首版目标是一款覆盖 **iOS、Android、Windows、macOS、Linux** 的统一客户端，**手机优先、桌面紧随**，让用户随时查看 agent、定位待处理终端并显式补充输入。五端共享协议、连接、状态和输入规则；App 内 **Tailscale 与 EasyTier 为首版必需，ZeroTier 同时纳入设计与集成目标**，三网络按平台分别验证。

实现契约见[架构](02-architecture.md)、[可靠性边界 ADR-0004](adr/0004-mvp-reliability-boundaries.md)及[统一五端 ADR-0005](adr/0005-unified-mobile-desktop.md)，实施顺序见[路线图](04-roadmap.md)。Flutter 为第一验证候选，Tauri 2 + xterm.js + Rust 为手机终端 A/B 的主要挑战者，最终框架由[技术评估](06-technology-evaluation.md)和实证决定。

## 1. 用户与前提

首版面向已有 herdr 和 SSH 主机的开发者，处理自己有权访问的 agent 和终端。用户已确定桌面首版只连接远端 herdr，本机已有会话接入放到后续；首版不提供 local socket 入口、本地 shell、daemon 或 WSL 管理，也不代装主机服务或管理团队权限。

- 用户能核对主机密钥指纹，并提供可用的 SSH 认证凭据。
- 使用内置网络时，主机已加入对应的 Tailscale、EasyTier 或 ZeroTier 网络，用户具有接入权限；加入网络不代表 SSH 或 herdr 自动可用。
- 支持的 herdr 版本、五端系统版本和主机环境由 M0.5 的兼容性验证确定。Windows 客户端可用不代表 Windows 能运行本地 herdr，未测组合不显示为已支持。

## 2. MVP 范围

用户已确定五端首版均提供完整交互终端，包括逐键输入、快捷键与交互 TUI；手机同样具备这些能力，以任务操作为默认入口并增加输入辅助。下表的快捷键条、组合键、草稿和粘贴预览是落实这一目标的默认设计，不代表用户逐项指定了具体控件。

| 当前 MVP 基线包含 | 当前后置规划 |
| --- | --- |
| 五端共享核心、多终端标签；手机切换、桌面分屏 | 本机已有会话接入、独立多窗口 |
| 手机扫码配对、手动添加兜底、核对指纹与连接诊断 | 主机安装向导 |
| 按主机分组的看板、待处理项优先、终端观察 | 团队权限、跨设备历史同步 |
| 完整逐键终端、快捷键与交互 TUI；手机快捷键/组合键辅助、草稿编辑和多行粘贴预览 | 结构化审批按钮；主动终端尺寸控制另定范围 |
| 字体诊断、已验证的 Nerd Font 选择 | 任意自定义字体市场 |
| 前台直连、App 内不同 provider 同时连接；Tailscale + EasyTier 必需、ZeroTier 同批集成目标 | 同一 provider 任意多身份/多实例并发 |
| 本地配置/偏好及加密导入导出、凭据安全保存；先源码与测试渠道、逐步正式上架 | 云账号/自动同步、文件、Git diff、会话历史 |

用户已确定后台通知后续再做，首版提供前台状态；配置保存在本地并支持加密导入导出，手机扫码配对是首版必需。**不承诺锁屏通知或休眠期间持续在线**，不引入云账号或自动配置同步。首次直连演示不能替代各内置网络验收；ZeroTier 的技术与许可未验证前不宣布支持，也不从集成目标中删除。

## 3. 页面与核心路径

手机采用“按主机分组的看板 → 多终端标签”，在标签间切换，终端详情可显式进入完整交互模式；任务入口和输入辅助不能代替完整终端能力。桌面采用主机侧栏、待处理列表与终端工作台，首版支持标签和分屏，适应窗口调整、键盘导航、选择与粘贴；不能把手机页面原样放大。

标签保留 herdr session/目标、草稿、滚动位置和界面状态；隐藏标签可暂停绘制或观察，显示暂停标记与更新时间，这不会停止远端任务。任务状态订阅与终端绘制分开；暂停观察后重新显示须取得当前状态与新全量画面再开放输入，恢复的是当前画面，不保证补齐暂停期间的终端历史。桌面多个可见终端仍只有一个明确输入焦点，显示主机、session 与目标；快捷键、IME 提交和粘贴不能流入非活动分屏。分屏拖拽只调整本地布局；远端 resize 须独立显式操作并通过接口验证，不自动接管共享 PTY。

两类布局使用同一信息模型，均显示连接状态、同步时间、主机与目标。默认观察，显式进入逐键输入或草稿编辑；主机管理提供地址、SSH 凭据、指纹和连接诊断，网络管理独立提供三网络的配置与身份管理。快捷键不能绕过目标核验、粘贴预览或发送状态规则。

终端提供字体诊断入口，能核对当前字体与测试字符。用户可选择已验证的字体；缺字或列对齐异常时给出无图标主题的配置建议，不自动修改远端 zsh、Oh My Zsh 或 Oh My Posh 配置。首版不引入任意字体安装市场。

首次使用：手机扫码（或手动添加）→ 预览连接信息 → 完成所需网络/SSH 授权并核对主机指纹 → 用户主动连接 → 验证 herdr 能力 → 进入看板。扫码或导入本身不连接、不信任 host key、不发送输入；指纹变化、认证失败、herdr 不可用分别显示。

### 扫码配对与本地配置迁移

新用户无需先安装本项目桌面 GUI。用户已选择在已有 herdr 主机上运行本项目一次性辅助命令，主机端展示目标账号与手机专属 SSH 公钥指纹，用户明确确认后添加公钥，完成后退出；已有桌面端导出作为补充入口。手机公钥通过已有可信访问渠道或手工送到主机，不新增配对网络监听，不假设两端处于同一局域网。

扫码展示主机、网络类型与指纹等可审查信息。普通连接资料码可复用；配对请求/响应才按已验证的状态检查过期、错配与重复完成，不能宣称离线静态码天然一次性、防篡改或可撤销。扫码后仍可能需要加入目标网络、授权手机 SSH 公钥并核对来源与指纹；实际 SSH 认证成功才算配对完成，失败可退回手动配置。若主机已确认添加公钥但连接未成功，显示“已授权、尚未验证”；二维码到期不代表主机授权已经撤销。

辅助命令提供明确的撤销方式，只定位并移除本次新增的授权项，不删除既有或其他设备公钥。撤销会限制后续认证，不宣称已经断开现有 SSH 连接；实际添加或撤销时仍由主机用户确认。

五端支持本地连接配置与偏好的加密导入导出。导出前显示范围，导入时预览新增、覆盖、冲突、缺失认证项与受影响标签/连接；不覆盖已信任指纹或自动连接。确认替换在用配置后停止相关连接与自动重试，等待重新核验和主动连接。设备 SSH 私钥和 overlay 节点身份不直接跨设备复制，密码、入网秘密等按[配对与迁移 ADR-0007](adr/0007-pairing-and-config-transfer.md)的分类规则处理；新设备独立取得所需认证。错误口令、篡改或不支持的格式不得部分导入，不把本地迁移扩为云同步。

日常使用：查看待处理项 → 打开终端 → 确认当前上下文 → 显式输入 → 观察反馈。主机不可达时保留其分组及最后同步时间，不能用空列表表示没有 agent。

草稿按目标保存。切换目标不沿用前一个目标的发送动作；原目标消失后可以复制草稿，不能自动转发到同名 agent 或其他终端。

### 网络配置、主机与切换

用户按网络类型创建配置，填写对应的网络标识、接入地址与认证项，再让主机的候选路径引用它。网络身份/秘密与 SSH 凭据分开保存；不同类型或不同配置的状态与秘密不能混用。普通诊断不输出节点私钥、network secret、token 或带秘密的完整接入地址。

同一网络配置可以服务多个主机，连接目标时才启动所需节点。断开一个主机只释放其连接，不能登出其他主机共用的网络；停用、切换或删除网络前展示受影响主机。删除本地配置、退出网络和清除节点身份是不同动作；停用不保证销毁底层运行时或立即切换身份，界面按各类型实际能力提供操作。

首版支持应用前台同时连接不同 provider 的网络及其主机。正式核心平台须通过 Tailscale + EasyTier 并发；声明 ZeroTier 支持的平台还须通过 Tailscale + ZeroTier、EasyTier + ZeroTier 和三者同开，不把单网通过当成并发通过。不承诺同一 provider 任意多身份/多实例并发，也不因此承诺后台常连。显式切换、停用及普通连接/鉴权错误应限定在相关配置，不主动关闭其他有效连接；恢复前重新核实身份、当前状态与全量画面，不重放旧输入。

跨网络的候选地址仍须验证为同一受信主机。重叠虚拟 IP 必须验证连接实际进入所选网络；配置标签不等于隔离，底层不能定向时拒绝该并发组合并提示显式切换。此时该组合保持实验/未支持，不能以切换降级冒称已满足并发要求。

候选路径只使用已配置且可用的网络，不自动弹出三种登录流程。需要认证的配置显示需要用户操作，完成明确接入后再参与连接。

网络状态与主机状态分别显示：配置缺项、接入待授权、节点未就绪、目标不可达、SSH 失败和 herdr 不可用应给出可区分的反馈。只在对应 provider 能提供证据时显示具体原因，未知原因不得伪装为“网络密码错误”。节点与路由契约见[三网络 ADR-0006](adr/0006-three-overlay-providers.md)。

## 4. 状态与新鲜度

业务状态与连接状态分别呈现。主机报告的 agent 状态可能来自启发式判断，客户端说明来源，不把推断升级为确定事实。

| 用户看到的状态 | 显示条件与行为 |
| --- | --- |
| 待处理 | 最新信息报告需要用户介入且可定位当前目标。展示主机报告与可用上下文，不凭关键词认定存在审批选项。 |
| 处理中 / 已结束 | 仅在已核实的服务端状态能映射到该含义时显示；否则保留原始状态说明或显示状态待确认。 |
| 状态待确认 | 状态缺失、无法解释，或恢复后尚未取得当前快照；未知不当作空闲或成功。 |
| 失去连接 | 显示最后同步时间，原业务状态标为上次状态，关闭发送入口。 |
| 正在恢复 | 正在重新连接并刷新状态，旧画面只作参考，明确标记尚未恢复实时显示。 |

连接成功不代表页面内容已经刷新。列表显示最近一次成功同步时间；终端等到新一轮全量画面后才恢复输入。刷新频率与过期阈值根据 M0.5/M1 的实际能力确定并写入验收配置。

事件缺失后重新获取当前状态，不宣称补齐完整历史。待处理排序只依据当前有效状态，过期记录显示为待确认。

## 5. 显式输入与发送反馈

默认观察终端；用户显式进入“逐键输入”后，已提交文字和明确按键直接作用于当前目标，支持交互 TUI，不逐键弹确认。也可选择“草稿编辑”后显式发送。当前模式与目标持续可见，观察模式不发送按键。这些界面模式不等于服务端只读权限，不能替代 SSH 权限限制。

- 两种输入模式都不把中文输入法组合阶段写入远端；逐键模式在输入法提交后发送一次，草稿模式继续在本地编辑，等待用户发送。
- 草稿“发送文本”按预览内容发送，不额外补回车；逐键模式的回车、方向键及组合键按用户动作发送。手机提供常用快捷键与组合键辅助，不能将快捷键按钮变成自动审批。
- 两种模式的多行粘贴都先预览，保留其换行，并提示换行可能被终端解释为执行输入。
- 草稿或辅助按钮的同一发送尝试尚未确定结果时，重复点击不能再次提交；逐键模式保留用户有意连续输入的顺序，不能把重试当作新按键。失败或目标变化不清空未发送草稿。
- 默认观察不接管共享终端尺寸；进入逐键模式也不自动取得尺寸控制权。本地字号、软键盘与视图调整不能静默 resize 远端 PTY。

下表用于草稿和明确输入动作的反馈；逐键模式汇总连接与发送异常，不为每个键弹出确认。目标切换、断线或写入结果不明时立即停止继续输入，取消尚未发出的临时按键并提示，不离线积压；已发出但结果未知的内容不转回待发送草稿。恢复后先核实当前画面与目标，再由用户显式继续输入。

| 发送状态 | 含义与可用操作 |
| --- | --- |
| 未发送 | 草稿仍在本地，可以编辑、删除或主动发送。 |
| 正在发送 | 请求已经发起但尚无明确结果，同一动作不能再次提交。 |
| 服务端已接收 | 已明确确认输入写入；查看终端反馈。这不表示命令执行完成、任务开始或审批通过。 |
| 未发送成功 | 能明确证明请求未被远端接受；修正问题后由用户重新发送。 |
| 发送结果待核实 | 发出后断线或超时，无法判断远端是否接受；恢复后先查看终端，由用户判断是否再次操作。 |

**离线不排队自动发送，重连不自动重放输入。** 待核实状态保留发送内容、目标和时间供本机查看，不将这些内容自动上传到诊断日志。任务结果只能在重新获取实际状态后显示。

发送前必须核实主机、选定的 herdr session、pane 和当前目标身份。RPC 与终端观察必须使用同一个 session；重连不能从命名 session 静默退回 default。原目标退出、替换或身份无法确认时，关闭发送并要求重新打开目标；具体契约见 ADR-0004。

## 6. 审批与后台恢复

MVP 不提供可执行的一键批准按钮，不从 ANSI 画面解析生成授权操作。可以展示原始问题供用户阅读，但所有回应通过当前终端的显式人工输入完成。“待处理”不等于已经取得可靠的授权选项。

结构化审批留待后续：只有上游提供可以绑定当前问题、核实有效性并明确提交结果的正式契约，才重新评估按钮交互。断线、目标变化和问题变化后，旧上下文不能继续用于操作。

手机进入后台、桌面系统休眠或应用被挂起后，不承诺持续收集输出或周期刷新，草稿留在本机。恢复或切网后，先建立可信连接、获取当前状态、重新观察目标，再在收到新全量画面后开放输入。恢复期间显示正在恢复，旧连接迟到的数据不能覆盖新内容。

目标已退出时显示原终端已结束或不可访问，保留草稿供复制。用户停用或退出某网络后，停止相关连接与自动重试，主动重新接入后才能恢复；其他网络不受连带停止。后续通知只负责提醒，点击后仍需核实当前目标与状态，通知本身不触发输入。

## 7. 产品验收

移动端使用真机，桌面端在各目标系统实际运行。每个用例记录设备、系统/架构、herdr 版本和网络条件，在独立测试目标上执行，不向用户现有工作终端发送探测内容。

| 场景 | 必须观察到的结果 |
| --- | --- |
| 首次连接与指纹变化 | 正常配置能进入看板；错误凭据、未信任或变化的指纹不会被自动绕过。 |
| 手机扫码与手动兜底 | 无本项目桌面 GUI 也能完成配对；主机确认后只添加手机专属公钥，撤销只清理本次新增项且不冒称现有 SSH 已断开。畸形/错配/过期响应被拒，静态资料码不冒充一次性授权；扫码不静默信任或发送，相机不可用时可手动接入。 |
| 加密配置迁移 | 五端可导出并审查导入连接配置/偏好；错误口令、篡改、版本不兼容均不部分写入，冲突可见；设备私钥/节点身份不复制，导入不自动连接或覆盖已信任指纹。 |
| 从看板处理待办 | 打开的终端与主机、herdr session 和目标一致，重连不落到 default；发送前可核对上下文，反馈不夸大执行结果。 |
| 五端完整交互终端 | 手机和桌面均能显式进入逐键模式，以文字、方向键、快捷键/组合键完成指定交互 TUI fixture；观察与草稿模式不会意外向远端发键，不能用草稿演示替代完整终端验收。 |
| 手机辅助输入 | 默认任务入口能进入完整终端；快捷键/组合键辅助、草稿与多行粘贴预览可用，软键盘显示、模式切换与焦点变化不丢字、不重复发送、不串目标。 |
| 多标签与桌面分屏 | 手机可切换多个终端标签，桌面可同时查看分屏；各自目标、草稿与 UI 状态独立，输入焦点明确。隐藏标签不持续渲染也能恢复，旧画面更新前不能输入；拖拽分屏不静默 resize 远端。 |
| 中文、英文、组合键、多行粘贴 | 测试终端收到的内容与预览一致；中文组合过程未提前写入，发送文本未附加回车。 |
| Nerd Font 与主题 | 五端分别跑纯 zsh 基线、选定的 Oh My Zsh 主题（含 Powerlevel10k 图标配置）、Oh My Posh 图标 prompt；核对 Powerline 箭头、Git 分支、PUA、CJK、emoji 与组合字符。字体需求取决于具体主题配置，不将 Oh My Zsh 框架本身当作统一字体要求。 |
| 字体列宽与输入 | 同一 fixture 验证 IME、光标列对齐、长行换行、本地字号/观察视图 resize 和异步 prompt 重绘；不无提示改变远端 PTY 尺寸。图标截图可见不等于输入光标与列宽验收通过。 |
| 连点发送、逐键过程中断网 | 草稿/按钮提交不因连点重复；逐键发送结果不明后停止输入，不留离线按键队列；显示待核实，恢复后不补发。 |
| 后台/休眠恢复、切换网络 | 旧状态有标记，当前状态与新画面恢复后才能发送，无重复输入或旧帧覆盖。 |
| 桌面窗口与键盘 | 调整窗口、切换焦点、选择复制和快捷键不改变目标、不意外发送；窄窗口仍能完成核心流程。 |
| 目标退出或替换 | 旧页面不能向新目标输入，草稿可以复制。 |
| 审批问题出现或变化 | 不出现可执行的一键批准，仍可查看原始终端并人工输入。 |
| 每个 provider × 平台的独立连接 | 关闭对应系统网络客户端、主机无公开入站路径时，由 App 内节点完成看板、终端与输入闭环；只获得网络地址不算通过。 |
| 前台跨 provider 并发 | 同时经 Tailscale 与 EasyTier 连接不同测试主机，各自完成终端输入；停用/断开一网不停止另一网，身份、IP 路由与输入目标不串用。声明 ZeroTier 支持时，还须逐项通过它与另两网的两两组合及三者同开。 |
| 多主机复用与网络切换 | 断开一个主机不停止同配置的其他主机；切换/停用范围明确，恢复前不能输入，不串用身份、秘密或目标。 |

候选测试包优先由云端 CI 生成，再在同一组移动真机、输入与输出 fixture 上比较正确性；通过后使用各框架适当的性能测量构建记录帧时间、内存及输入反馈延迟。记录构建模式，不拿 debug 与优化构建直接比较。CI 编译、模拟器或自动化成功不替代触控、IME、扫码、字体、真实网络与恢复验收。预算须在 M1 前明确，未设预算或超出预算不能以主观流畅通过。

## 9. 决策状态

- **用户已确定**：公开开源且希望衍生改动继续开源；五端目标、手机优先桌面紧随；完整终端与手机辅助；仅远端 herdr、TS+ET 必需且 ZeroTier 同期、Nerd Font；前台跨 provider 并发、多标签/手机切换/桌面分屏；源码与测试渠道先行、云端 CI 构建优先与本地轻量；首版前台状态、通知后置；本地配置加密导入导出；手机首版扫码配对，手动兜底。
- **配对方式已确定**：一次性主机辅助命令，经主机用户明确确认添加手机专属 SSH 公钥，并提供仅针对本次新增授权的撤销方式；不引入新账号、配对监听或常驻服务。已提出的产品问题均已回答。
- **由技术验证负责**：具体框架、终端与 SSH 库、最低系统版本、原生桥和支持矩阵；具体许可证按已定开源立场进行依赖与分发审查后确定，不把调查工作转交用户选型。
