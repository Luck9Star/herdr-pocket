| 已有规则 | 首轮需要补齐的界面规格 |

| 观察、逐键输入、草稿编辑及安全恢复 | 模式切换、软键盘展开、辅助键、焦点、粘贴预览和禁用原因 |

## 2. 三条优先验证的用户旅程

### J1 · 新手机配对并首次连接

1. 手机生成设备公钥请求，展示可信渠道/手工传递方式；同时提供已有 SSH 凭据与手动配置入口。
2. 主机操作者通过现有可信终端运行一次性辅助命令，核对账号、公钥指纹和拟追加项，明确确认后生成响应码并退出。
3. 手机扫码，核对待处理请求、设备公钥、目标账号与预期主机指纹，预览连接资料并核实来源。
4. 分开完成所需网络入网与 SSH 授权，主动连接并核对实际主机身份；SSH 认证成功后验证 herdr 能力、进入看板。
5. 演示相机不可用、响应过期/错配、拒绝授权、指纹变化和网络不可达；保留“已授权、尚未验证”及撤销指引。

双端画稿包含辅助命令的文字输出与确认步骤，不虚构手机已能回传公钥、同一局域网、常驻监听或必须先装桌面 GUI。撤销只处理本次新增授权，不声称中断现有 SSH；详见[配对 ADR](adr/0007-pairing-and-config-transfer.md)。

### J2 · 从待处理项进入完整终端

1. 从主机分组看板进入准确的 herdr session 和目标，先观察当前画面与更新时间。
2. 显式切换逐键输入，展示软键盘、常用键/组合键辅助、当前模式与输入目标，保留交互 TUI 的完整操作路径。
3. 切换草稿编辑，演示未发送内容的保留、发送预览与结果；草稿发送不自动附加回车。
4. 两种输入模式均演示多行粘贴预览；输入法组合文字先留本地，逐键模式提交后发一次，草稿模式仍等待显式发送。
5. 演示键盘收起、标签切换、组合键状态和焦点变化，标注哪些动作改变本地界面、哪些会向当前目标发键。

原型模拟操作路径；真实输入、触控选择和终端字符格的正确性由手机 A/B 验证。辅助键不生成一键批准，布局或软键盘变化不静默调整远端 PTY 尺寸。

### J3 · 跨网络、多标签与中断恢复

1. 前台同时连接不同网络的测试主机，手机切换标签；桌面分屏显示两个目标，始终只有一个明确输入焦点。
2. 演示断开主机与停用网络的不同影响，停用前展示受影响主机，不误停其他有效连接。
3. 在逐键或草稿发送中断线，显示“发送结果待核实”，停止继续输入；不排队、补发或把未知输入转回未发送草稿。
4. 恢复可信连接、当前状态和新全量画面后，由用户核对目标并显式继续；目标退出或身份变化时只能查看、复制草稿与重新选择目标。
5. 隐藏标签恢复时展示暂停/更新时间；恢复当前画面不等于补齐暂停期间的全部历史，暂停观察不停止远端任务。

原型保留 Tailscale + EasyTier 并发路径；声明 ZeroTier 支持还需另外两种两两组合及三者同开。15 个单网络格与并发验收分别记录，不能用统一“已连接”勾选代替实测。

## 3. 首轮画板与状态清单

以下是画板族，每族使用必要状态变体；不要求为五个系统机械复制全部页面。系统权限弹窗标明调用位置，使用目标平台真实行为验证。

| 编号 | 画板族 | 必须覆盖的状态与操作 |
| --- | --- | --- |
| P1 | 手机导航、主机看板与待处理列表 | 空配置、加载、正常、旧状态/失联、待确认；主机不可达不显示成没有 agent |
| P2 | 手机配对 + 主机辅助命令 | 公钥请求、主机确认、扫码/手动、资料预览、入网/认证/信任分开；成功、取消、错配、已授权未验证、撤销说明 |
| P3 | 手机终端与辅助输入 | 观察/逐键/草稿、键盘展开/收起、辅助键与组合键、粘贴预览、标签切换、目标标识 |
| P4 | 终端异常与恢复 | 正在发送、服务端已接收、明确未发送成功、结果待核实、失联、恢复中、观察暂停、目标失效 |
| P5 | 主机与网络配置管理 | 主机路径引用配置；三类配置的必要字段/校验、待授权、节点未就绪、并发状态、诊断与停用影响 |
| P6 | 加密导出与审查导入 | 导出范围/排除项、口令、字段冲突、新增/保留/替换、缺失认证、受影响标签；错误口令/篡改/不兼容不部分导入 |
| P7 | 字体与显示诊断 | 已验证字体选择、测试字符、缺字/列对齐问题说明、无图标主题建议；不自动改远端 shell |
| D1 | 宽桌面工作台 | 主机侧栏、待处理列表、多标签与分屏、单输入焦点、鼠标选择、快捷键与焦点轮转 |
| D2 | 窄桌面与窗口变化 | 面板收纳/返回、分屏空间不足、键盘可达性；调整本地视图不静默 resize 远端 |

P3 至少展示小/大手机与软键盘占用后的可操作空间；D1/D2 标注布局变化规则。首轮不画可用的远端尺寸接管或 takeover 控件；若后续验证改变能力边界，先更新产品与架构契约。

## 4. 状态、动作与禁用理由

每张关键画板标注数据来源、目标身份、主次动作、返回/取消、保留内容及错误后的下一步；共享状态用表管理，避免不同页面各写一套含义。

| 状态 | 可做什么 | 禁止动作与说明 |
| --- | --- | --- |
| 未完成网络授权 / SSH 授权 / 主机信任 | 分别进入对应处理或手动配置 | 不能把扫码、保存资料或节点在线当作已配对；说明具体缺哪一步 |
| 旧画面、失联、观察暂停或恢复中 | 查看上次内容、同步时间和恢复进度 | 输入入口关闭；说明需取得当前状态与新全量画面 |
| 发送结果待核实 | 查看原目标/内容/时间，恢复后核实 | 无自动重试；已发未知内容不回填待发送草稿 |
| 服务端已接收 | 查看终端反馈与刷新后的状态 | 文案不显示为命令完成或审批通过 |
| 目标退出或身份改变 | 复制本地草稿、重新选择目标 | 旧标签不能向同名新目标发键 |
| 网络停用/身份操作 | 先查看影响范围，再按实际能力执行 | 不把断开主机、退出网络和清除身份合成一个动作 |
| 导入冲突或替换在用配置 | 审查新增/保留/替换及受影响连接 | 不自动映射秘密、覆盖信任或连接；替换后停止相关重试并等待主动核验 |

网络配置标签不能证明重叠地址已隔离；不能安全定向的组合显示未支持并说明切换路径，不能把切换当作并发已通过。未知错误展示已有证据，不猜成密码错误。

## 5. 小组件、视觉变量与可访问性

- 交付最小组件集：主机/目标条目、网络状态、时间与旧内容标记、模式切换、终端标签/焦点边框、辅助键、表单校验、影响范围与粘贴预览。
- 用统一名称记录颜色、间距、字号、边框与焦点等视觉变量（tokens）；区分应用文字与终端等宽字体，不靠设计稿决定终端字符格宽度。
- 定义辅助键的点按、组合键保持/释放和取消规则；定义桌面快捷键、焦点顺序及输入/应用快捷键冲突的处理，不让快捷键绕过安全规则。
- 状态不只靠颜色；按钮有可读名称，禁用给原因，焦点可见，文字放大与触控空间可用。终端可访问性限制单独在真实组件中验证，不由静态稿承诺解决。
- 状态文案和示例均用虚构主机、密钥指纹与终端内容；不把真实凭据、授权码或用户命令放进共享设计文件。

## 6. 设计与产品验收的对应关系

所有画板保留上表编号，原型与实现测试引用同一编号；规则来源统一指向[产品验收](05-product-design.md#7-产品验收)，不在设计文件另立支持声明。

| 设计交付 | 对应产品验收 | 运行证据 |
| --- | --- | --- |
| J1 / P2 | 首次连接、扫码与手动兜底、指纹变化 | 手机相机 + 一次性主机辅助命令 + 实际 SSH 成功/失败 |
| J2 / P3 / P7 | 完整终端、手机辅助、IME/粘贴、字体与列宽 | 同设备 A/B fixture，记录实际收到的输入与终端画面 |
| J3 / P4 / P5 | 多标签分屏、网络并发、未知结果、恢复与目标变化 | 每平台独立目标与故障注入，单网和并发分开验收 |
| P6 | 加密配置迁移 | 错误口令/篡改/冲突/在用替换，无部分写入或自动连接 |
| D1 / D2 | 桌面窗口与键盘、多标签和分屏 | 各目标系统键鼠、窄宽窗口与焦点测试 |

## 7. 交付顺序与完成条件

1. **低/中保真可点击原型**：先做信息架构、J1–J3 和关键失败分支，补 P5/P6 管理流程及 D1/D2；同步建立状态表与少量基础组件。
2. **真机反馈回流**：与 [M0.5](04-roadmap.md) 并行，用云端生成的候选测试包验证输入法、Nerd Font、触控、选择粘贴、视图空间、网络生命周期与无 GUI 配对；把失败结果回写画板，不以原型流畅代替技术通过。
3. **关键页高保真**：在上一步约束明确后定稿手机看板/终端/配对、桌面工作台及共享组件，补窄宽和异常变体；不用等待五端所有页面像素稿。
4. **实现组件与核验**：将视觉变量、组件状态、交互标注和产品验收映射交给实现；在实际 App 对照检查，不把设计工具的代码片段视为完整客户端实现。

首轮完成条件：三条旅程可走通成功与主要失败分支；输入目标、模式、旧状态和禁用原因始终清楚；配对双端、网络影响范围、导入冲突都有下一步；未实测能力明确标注待验证。关键流程审阅后可进入对应 M1 实现，剩余视觉细节随真机反馈迭代。

正式绘制须选定可访问的 Penpot 文件、核实编辑权限并记录画板链接和版本。2026-10-29规划时尚未接入；2026-10-30已通过官方MCP保存专用文件并重载核验，准确链接与兼容性警告见[设计入口](../design/README.md)。

Penpot 能力依据：[组件](https://help.penpot.app/user-guide/design-systems/components/)、[变体](https://help.penpot.app/user-guide/design-systems/variants/)、[视觉变量](https://help.penpot.app/user-guide/design-systems/design-tokens/)、[可点击原型](https://help.penpot.app/user-guide/prototyping-testing/prototyping/)、[开发者检查](https://help.penpot.app/user-guide/dev-tools/)与[工具连接](https://help.penpot.app/mcp/)。开发者检查提供规格及 SVG/HTML/CSS 片段，不生成完整 Flutter 或 Tauri App。运行与交付边界继续遵循[技术评估](06-technology-evaluation.md)和[云端构建与发布](07-build-and-release.md)。
