# 手机终端选区与复制

在手机观察页选择「选择终端文本」，会冻结该终端打开时可见的文本。用户可以长按选择，或用键盘调整选区，然后明确复制。没有选区时不写剪贴板。关闭后回到观察，再次逐键输入须单独开启。粘贴仍沿用[本地草稿预览](36-mobile-paste-and-auxiliary-input.md)。

## 画面与归属

- 从渲染后的活动缓冲区按可见单元格提取文本。只取完整可见的字符；宽字符被左右边缘截断时跳过。整行软折行可拼接，硬换行保留；窄屏裁去列时保留行间分隔。显式空格与组合字符按原样保留。
- 选区冻结后，同一目标后续输出不会改写已选文字。换目标、隐藏、断线或失去原观察代次后清掉面板与旧回调。复制期间没有远端发送操作，也不会调整共享 PTY。
- 单次快照最多 64 KiB UTF-8。超出上限、测不到可见区域或系统剪贴板拒绝写入时显示反馈。源文本不写入目录、日志或设备配置。

## 同条件验收

两端读取[同一份 UTF-8 fixture](../validation/shared/terminal-selection-v1.json)。在 6×3 的终端写入中日韩宽字符、组合重音、emoji 和显式空格，分别截取整页、左侧、从宽字符占位格开始的部分列和滚动后行。比较复制的原始字符串，额外检查目标切换、剪贴板拒绝、撤销逐键许可及零 PTY 调整。

1. 从新配对主机看板打开终端，或从已保存主机的新标签打开。先确认收到全量画面，再移动或缩窄视口。选择文本，确认没有被遮住的列、其他标签或离屏行。
2. 在逐键模式打开选择面板，选择含组合字符的片段，明确复制一次。关闭并按键，核对仍在观察模式。切换标签、停止观察或替换目标后，旧面板不可再复制。
3. 用独立测试接收端核对步骤 1 和 2 期间远端输入为 0，共享 PTY 保持原尺寸。真实手机的选择手柄、原生剪贴板权限与读屏反馈需要真机记录。

## 两种终端的实测差异与修复

Tauri 原先使用 xterm 6.0.0 的默认宽度规则。一个共享用例发现 `😀` 后的感叹号提前一列。进一步比较发现 Unicode11 provider 会把 `👩‍💻` 算作四列、家庭 emoji 算作八列。三个 Tauri 入口现已在首帧前使用固定的 `@xterm/addon-unicode-graphemes` 0.4.0。它通过 xterm 的实验性接口计算单元格与字素，单个测试的结果随上游版本固定。[上游固定来源](https://github.com/xtermjs/xterm.js/tree/f447274f430fd22513f6adbf9862d19524471c04/addons/addon-unicode-graphemes)

Flutter 的固定 `terminal_view` 0.5.0 在所测 emoji 变体上采用了预期列宽，缓冲区却没有保存输入的 VS15／VS16，复制 `❤️` 时会变成 `❤`。第 2 版候选补丁将选择符按原顺序保存在基字符的组合后缀中，沿用原来的列宽与光标推进。真实 Dart 核心的 23 个样例中，复制均满足预期，字符单元、属性、宽度和光标与修复前逐项一致。[候选来源及补丁摘要](../validation/flutter/patches/manifest.json)

| 同一输入后的感叹号位置（从 0 起） | Tauri grapheme 候选 | Flutter 修复候选 |
| --- | ---: | ---: |
| 👩‍💻、👨‍👩‍👧‍👦、🇨🇳、❤️、中、😀 | 2 | 2 |
| ☀︎、组合重音 é、Powerline U+E0B0、间隔号 · | 1 | 1 |

这 10 个输入的复制文本相同，两个真实缓冲区均通过 4 个共享裁剪样例。Tauri 在 Mac Chrome 156 的 320×820、390×820 视口，从配对表单与已存标签分别验证复制一次、左右裁剪和切换后拒绝旧操作。四个场景的远端发送与 PTY 调整均为 0。固定 Nerd Font 通过 HTTP 200、SHA-256 和浏览器字体加载状态三重核对；测试使用隔离的传输与剪贴板替身。隔离源码副本的 199 项 JavaScript 检查和前端构建通过。

Flutter 选区的渲染布局、系统选择手柄、真实中文输入法及两套候选在同一部手机上的性能仍未验证。先保持双路线，在下一批集中构建中运行新增 Flutter widget／绘制回归，再测试手机系统选区和真实剪贴板。当前可下载的两份 APK 仍来自前一批，未包含本页新功能。[可复核读数](evidence/mobile-pair-gui/mobile-terminal-selection-20261107.json) · [现有 Android 测试包](36-mobile-paste-and-auxiliary-input.md#同源云验证与可下载测试包)
