# 手机系统粘贴与草稿审查

手机在刚配对的终端表单或已存标签内启用草稿或逐键输入后，可以点「粘贴并审查」。Tauri 从当前平台读取纯文本，再显示原目标上的本地审查。Flutter 在读取为空、被系统拒绝或超过上限时保留原草稿。发送仍需单独预览并确认。

## 可复测的操作

1. 在隔离的测试会话内输入草稿 `Pocket`，将合成文字「测」放入测试设备剪贴板。打开审查并取消，原稿应仍为 `Pocket`。
2. Tauri 配对表单在取消后回到观察模式，需再次点「草稿」。重新点粘贴并选择追加，草稿变为 `Pocket测`，共 9 个 UTF-8 字节。在明确发送之前，检查独立测试接收端没有收到这些字节。
3. 将原稿改为 4094 个 ASCII 字符，再粘贴「中」。追加不可用，取消保留全部原稿，选择替换后仅保留「中」。单次粘贴上限为 4096 个 UTF-8 字节，超限内容不会出现在审查正文。
4. 在系统读取尚未返回时离开当前目标，回来后核对原草稿与远端输入。需要粘贴时再次发起审查。使用含 ESC、换行或双向格式字符的合成文本时，在预览中核对可见标记。

## 平台行为

| 入口 | 剪贴板与焦点 |
| --- | --- |
| Tauri Android | 启动时只查询壳的平台。用户主动粘贴时才调用原生读取。前台 Activity 须处于 resumed 并拥有窗口焦点。检查首项与 MIME，仅接受纯文本以及同时提供纯文本的 HTML。拒绝 URI 与 Intent，超过字节上限时只返回固定错误码。 |
| Tauri 其他 WebView | 在用户手势内调用浏览器纯文本读取接口。拒绝、不支持和无焦点均给出本地反馈。系统派发的粘贴事件也经同一草稿审查。 |
| Flutter | 通过系统纯文本剪贴板接口读取，拿到字符串后在 UTF-8 长度超过上限时停止扫描。过大的文本不存入审查模型。剪贴板和草稿分别在上限内时，合并超限仍可选择替换。 |

Flutter 的粘贴审查以临时 Route 显示。标签隐藏、应用离开 resumed、断线、目标改变或页面销毁时，会同步撤销审查凭据，再于当前帧结束后清空预览并移除该 Route；若上方另有 Route，只移除本次粘贴审查。正常取消、追加和替换仍由用户明确操作。此项为源码修复，当前 Flutter widget 尚未运行验证。

## 验收范围
