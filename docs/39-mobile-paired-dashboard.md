# 新配对后的持续会话看板

2026-11-07 后续云验收已完成，两款 APK 和四个 Android 场景均已复核。[下载、逐场结果与测试步骤](40-android-paired-dashboard-validation.md)

2026-11-07 的 Tauri 候选改动让新配对表单主动连接后，在同一已认证 SSH 连接上持续接收会话看板与所选终端画面。下文的本地数据来自提交前的隔离验证；后续 Android 结果见上方云验收记录。[检查数据](evidence/mobile-pair-gui/mobile-paired-dashboard-20261107.json)

## 行为与边界

配对响应、主机公钥、设备身份和目标经用户核验后主动连接。看板显示同步状态、当前 pane 与任务摘要；终端打开后看板仍持续更新，主机摘要使用同一主机和会话的最新有效报告。无法订阅时明确标示“持续更新不可用”，仅将一次快照作为本次快照；刷新中、停止或断开时旧内容标陈旧，未知状态不计作零。

选择绑定看板代次、修订号、pane 和 terminal 标识。行变化、旧修订、取消后的迟到结果不能重新获得选择权；原目标不一致时停止，需重新核验。后台或离线结束当前观察；窗口失焦会撤销输入焦点许可并关闭粘贴审查，但看板观察继续。不会自动重放输入。全帧与增量帧独立更新终端，屏幕或键盘尺寸变化不请求远端 resize。实际系统权限弹窗对输入焦点和粘贴审查的影响仍需在设备上验证。

## 本地验证

- Mac 无头 Chrome 在 320 × 820 和 390 × 820 视口使用 CDP 触摸，走新配对表单与替身传输：每组各一次观察，验证旧按钮和旧修订拒绝、选择变更后的目标、全帧和一帧增量的确认、取消后摘要陈旧；远端发送和 resize 请求均为零。这不是手机、真实 SSH 或原生 IPC 证据。
- Tauri JavaScript 215 项通过，覆盖表单入口、摘要新鲜度、目标与旧事件拒绝，以及既有输入、草稿和粘贴测试；其中普通窗口失焦后可见看板保持订阅，测试使用模拟边界。Vite 构建通过 51 个模块，构建不证明安装或原生运行。
- 共享 Rust transport 86 项和 Tauri 原生库 41 项均通过。86 项中的 4 项定向测试另行重跑通过：在 loopback SSH 测试夹具中，配对 signer、看板与终端共享一条连接，全帧等待确认期间仍收到看板更新，随后确认增量；另核对旧代次／替换目标、取消和不支持订阅。使用测试密钥和模拟服务，不等于 Android 真实设备或真实网络。

## 复测步骤

1. 在隔离测试主机完成设备配对，独立核对主机公钥、设备身份及会话后主动连接；确认首次看板与同步状态。
2. 保持终端全帧和增量流运行，在主机侧变更 pane 或任务状态，确认看板和摘要更新；核对旧行不可选，终端仍持续刷新且无意外输入或远端尺寸变化。
3. 使应用进入后台、断网或主动取消，确认旧摘要标陈旧、迟到事件不恢复当前状态；恢复前重新核验，另记录普通失焦和系统粘贴弹窗对输入与看板的影响。

## Android 首轮构建复核

集中构建在 `d56ca78` 上验证了共享 Rust 传输的 101 项库测试和 1 项命令行测试。Flutter analyzer 发现粘贴正文的可空通知器和测试中的目标类型各一处错误，其中前一处阻断了 APK 编译，组合字符专项 10 项通过。Tauri 打包前的 Node 22 测试在两项 Unicode 用例报错。该依赖的 Node Buffer 可能从内存池中间起始，解析器从整块缓冲区开头读取；WebView 使用单独分配的字节数组。测试修复后，精确候选源码在固定 Node 22.22.2 和 Node 24.22.2 上均通过 215 项，仍实际加载同一 Unicode provider。两份 arm64 包均未产出。同批 Tauri 的两个 API 35 x86_64 模拟器场景实际通过。终端打开前后看板都保持 fresh，只读场景收到 0 字节，受保护输入场景在同一目标收到 1 和 9 字节，两个场景都没有观察到共享 PTY 尺寸变化。[首轮运行与日志](https://github.com/Luck9Star/herdr-pocket/actions/runs/42360984554)
