## 从手机交给主机

1. 在隔离测试账号生成连接资料。将资料扫码或粘贴到手机，先查看完整主机、账号、会话、路径及公钥指纹。用独立可信渠道核对指纹，明确填入和勾选，再点创建设备身份。设备私钥留在本机。[生成公开连接资料](../helper/README.md)
2. 手机显示原请求编号、账号、主机指纹、设备指纹及到期时间。请求有效且仍在等待授权时，可明确复制完整 JSON。复制失败可手动选取原文。Tauri Android 根据本机主机及请求编号，在原生端重新核对记录、有效期和应用窗口，再复制原请求；Flutter 在点击时核对当前请求，系统复制返回后再次检查请求有效性。两端均不读取系统剪贴板来校验。
3. 主机操作者运行 helper 的 `preview`，逐项核对后用 `authorize` 在控制终端输入完整确认短语。手机再次核对回执来源及原请求信息，接受后点击连接。SSH 验证固定主机公钥，并由该手机的设备公钥对应身份完成认证。到达看板后选择确切 pane，等待完整画面和后续增量，再点停止。本次只读观察的验收条件包括远端收到零输入、共享 PTY 尺寸保持原值。[看板与观察行为](39-mobile-paired-dashboard.md)
4. 结果未知、超时或取消时保留原编号。主机可用同一账号、原主机公钥和原编号运行 `inspect`，只读检查这一条收据和当前授权项。操作人再次核对后运行 `revoke`，在控制终端确认。重复、外部编辑或原已存在的公钥须人工核查；原请求过期也不能延长授权。[helper 的核查与撤销步骤](../helper/README.md)
5. 手机仍持有原请求时，即使已取消等待或请求过期，也能审查新鲜撤销回执。回执须匹配原编号、账号、主机及设备指纹，有效窗口最长 600 秒。接受后禁用连接并保留本机身份引用；Tauri 区分本次运行已禁止连接和目录已确认持久化。清理本机身份是另一次显式操作。主机撤销限制后续认证，已有 SSH 连接的结束由操作者单独确认。
