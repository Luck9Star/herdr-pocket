# ADR-0007 · 手机扫码配对与加密配置迁移

状态：**已接受首版范围、安全边界与一次性 helper 流程**（2026-10-29）。用户已选择主机端确认后添加手机专属 SSH 公钥，并提供撤销方式。手机扫码、本地配置与加密导入/导出进入首版；后台通知后置。本记录是客户端设计，不是现有 herdr API，也没有实际配对或加密实现。

## 范围与秘密分类

首版仍只连接远端 herdr，不引入云账号、配置自动同步或常驻主机 relay。五端配置保存在本机；加密导出文件供用户自行传递，导入不会自动连接、信任主机、启动网络或发送输入。

| 内容 | 连接资料 QR | 加密配置文件 | 导入后的处理 |
| --- | --- | --- | --- |
| 主机名称、地址/端口、SSH 用户、jump、herdr session/socket/CLI 定位 | 仅所选主机的必要字段 | 可选主机及相关配置 | 预览与校验；远端路径只作数据，不作为本机写路径或待执行命令 |
| 预期 host key/指纹 | 可以包含，展示来源 | 可以包含参考值 | 不继承可信标记；与实际 SSH key 比较并显式核验来源 |
| 网络类型、网络 ID/控制端地址等非秘密配置、UI 偏好 | 只包含接入所需引用，不含 UI 偏好 | 可以包含已列入白名单的字段 | 新建本机 profile 引用；缺少秘密显示待授权，不静默借用同名配置 |
| SSH 私钥、密码、overlay 节点 identity/state、入网共享 secret、长期 auth token | **排除** | **默认排除，首版不提供跨设备克隆选项** | 目标设备独立生成/提供凭据，重新入网与授权 |
| 终端内容、输入草稿、发送历史、日志、运行中连接/租约 | 排除 | 排除 | 不迁移运行状态或未确认操作 |

字段是否属于秘密按具体 provider/schema 白名单审查，不能因为位于“配置”对象就自动导出。控制端等 URL 的 userinfo、query 或 path 也可能含凭据，只迁移经 provider 解析确认的非秘密部分，不默认导出整条 URL；被移除的认证信息在目标设备标待补。导出界面列出包含与排除项，提醒目标设备仍需授权；加密不作为复制设备身份的理由。已有 SSH 凭据仍可通过单独的受保护凭据入口使用，不经 QR 或配置文件搬运。

## 扫码不等于 SSH 授权

连接资料 QR 只减少输入，不是 bearer 凭据或服务器授权。手机先显示主机、账号、route、session 与预期指纹，用户核实来源并决定保存/连接；未知来源不能自动加入 trusted host keys。连接仍执行实际 host key 验证，再发送认证凭据。扫码成功、资料保存、SSH 授权成功与当前网络可达是四种状态。

默认每台设备独立生成 SSH 密钥，私钥只进该设备受保护存储；可显示公钥及指纹供主机授权。**不能仅因扫码就写 `authorized_keys`**。主机侧必须显示目标账号、公钥指纹和拟议变更，由已有该账号访问权的用户明确授权；也可由用户自行安装公钥。helper 仅在本次主机端确认后写入，只在当前目标用户权限内处理，以实际账号/UID 与 home 解析授权路径，不接受 QR 指定本机写路径，不自动 sudo 或修改其他账号。公钥经库解析为规范单条记录，拒绝换行及夹带的任意授权选项；幂等追加而不覆盖既有文件。非标准认证配置、权限不足或无法确认路径时停止并转手工。公钥请求不是已获授权的证明，最终通过 SSH 认证核验私钥持有权。

首版必须验证一条**无需先安装本项目桌面 GUI** 的手机初次接入路径：

1. 用户通过已有可信方式访问目标主机，例如现有 SSH 终端或主机控制台；在此取得主机连接资料与指纹。手机此时不必已连上该主机。
2. 已有 SSH 凭据的用户可先扫码资料，再从独立凭据入口提供凭据。新设备路径由手机离线产生公钥请求，经用户控制的带外方式交给主机操作者；不暗含手机到主机的回传网络。
3. 新设备路径在主机操作者核对并授权公钥后显示响应码；手机必须核对当前待处理请求 ID、手机公钥指纹、目标 SSH 账号与预期 host key，再预览与显式连接。绑定只证明对应哪次请求，不替代可信来源核验；普通可复用连接资料码另用类型区分。传递可经主机屏幕或现有可信终端，不要求同一局域网。
4. 手机必须另有可达的 SSH route；若需 overlay，先独立完成该 provider 的设备入网。离线 QR 不建立隧道，也不解决网络不可达或缺少授权操作者的问题。

**已选流程：运行一次性主机 CLI helper，主机端确认后添加手机专属公钥，并提供撤销方式。**它是拟建的本项目工具，不冒充现有 herdr 命令；从手工传入的公钥请求展示授权变更、确认后安全追加并生成响应码，执行后退出。公钥经用户已有可信访问渠道或手工传递，不另造隐含上传协议；工具不安装常驻服务、不监听端口、不假设同 LAN，也不依赖本项目桌面 GUI。该产品选择不跳过每次主机端确认；在无 GUI 闭环实测前，不能宣称首次扫码已经可用。已有凭据和手工授权仍作为兼容路径。

helper 与 GUI 分开构建和发布，优先用云 CI 产出对应源码、构建材料、校验和及实际实现所需的运行说明。只声明已验证的远端 Unix 主机 OS/CPU，不从 Windows GUI 推出 Windows herdr/helper 支持，也不要求主机安装完整 GUI 工具链。CI 在临时测试账号/home fixture 验证公钥写入与撤销，不操作维护者真实授权文件；下载已发布 helper 不替代运行时的主机端确认。产物策略见[云端构建与测试分发](../07-build-and-release.md)。

## QR 与配对状态边界

QR 使用带版本和类型的有限 schema；连接资料与设备公钥请求/响应明确区分。限制总字节数、字段数量/长度、嵌套深度与路径长度，拒绝未知必须字段、控制字符和不支持的版本；不从码中自动打开 URL、执行命令或导入任意文件。公钥类型/格式与 host key 表达必须由选定 SSH 库验证，不能只校验字符串外形。

有期限的配对记录应绑定请求 ID、设备公钥指纹、目标账号与过期时间；手机拒绝错配、已完成或过期的请求响应。具体编码和校验方案在实现前固定。**普通连接资料码可能可复用，不宣称离线静态码天然一次性、防篡改或可远程撤销。**若要提供真正一次性授权，主机端必须维护消耗状态并验证；没有该实现前不作此承诺。结构校验、过期检查不能证明来源可信，所有未知来源仍需显式核验。

取消、过期、拒绝授权或网络不可达保留明确结果，不自动生成额外凭据或循环申请。若主机已经添加公钥而 SSH 尚未成功，显示“已授权但未验证”；QR 过期或手机取消不自动撤销长期公钥。提供明确撤销/清理指引，仅识别本次实际新增的 key，不删除此前已有的相同 key 或其他授权。配对请求与导入内容不进入普通日志；不拍摄或保存包含凭据的额外屏幕内容。

## 加密文件与导入事务

导出使用版本化封装、成熟库提供的认证加密与口令派生方案；具体 AEAD/KDF、参数及库须经后续技术核查与跨五端测试确定，**不自制密码算法或在此虚构已选实现**。格式必须保护数据与关键格式/版本字段的完整性；salt/nonce 等由库要求安全生成。口令不进入文件、日志或自动同步。

读取先限制文件体积、头部长度及 KDF 资源参数，再解密与验证完整性；之后按 schema 限制对象数、字符串/路径长度和嵌套深度。错误口令、截断、篡改或未知版本均不部分导入，不以明文方式继续；提示“无法验证或解密”及可确定的版本/格式错误，不猜测来源。数值上限由 M0.5 固定并测试，不能由导入文件自行放大资源预算。

解密成功也不证明来源可信。导入先展示字段、主机/profile 关联、缺少凭据和冲突；用户逐项选择新增、保留或明确替换，禁止按同名主机静默覆盖受信 key、秘密引用和目标定位。重建本机 ID/引用，不复用另一设备的密钥存储标识，也不按导入 ID/profile 名自动匹配本机 secret；只能重新授权或由用户明确映射。被替换配置仍须重新核验信任。确认前不写入，确认后配置存储原子提交或完整回滚。首版只解析数据，不按文件内路径写本机文件或执行远端 CLI。

替换活动 Host/profile 时先展示受影响标签与 lease，用户确认后使相关 generation 失效、停止自动重连并关闭受影响连接，不改动其他配置的连接。配置提交不等于活动会话可原子回滚；提交失败也不能静默重连。新配置或保留的旧配置均待用户主动连接，不能因导入重新发送按键或改变现有终端目标。

## 首版验收

- 手机真机在没有本项目桌面 GUI、没有常驻 relay 的条件下完成资料获取、预览、独立 SSH 授权及连接；已有凭据与新设备公钥路径分别记录前提，网络不可达时明确失败。
- QR 验证错版本、超限、错请求/公钥、过期、重复响应与 host key 变化；没有授权状态/来源证据时拒绝把扫码显示为已信任或已授权。
- 五端加密导出/导入覆盖正确口令、错误口令、截断/篡改、未知版本、恶意长度/KDF 参数、冲突取消及原子失败；证明排除设备身份和秘密，导入不自动连接或发输入。
- 具体 helper、加密库、参数、字段白名单与上限尚未通过技术验证；只做文档或 round-trip 单测不能替代真机接入和失败路径验收。后台通知不进入首版关口。
