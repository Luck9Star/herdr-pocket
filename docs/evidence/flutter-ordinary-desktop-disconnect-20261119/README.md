## 路径与结果

修前从正常首页点击普通 SSH 并填写目标；终端状态为测试注入，随后实际点击断开和返回。三档均无 `direct-return-home` 按钮，返回首页无断开提示。这些图只证明 Widget 行为和几何，不证明 SSH 通信。

修后用仓库原始 Paramiko 夹具，仅监听一次性 `127.0.0.1` 端口，从正常首页点击普通 SSH，填写目标、探测、点击指纹确认、输入测试密码、连接 PTY、点击断开、点击返回。三档首页直达以及 700 宽度的选择页入口共四条通过。1440 与 980 下现有“添加”入口直接进入配对，而非选择页，故两条选择页路径不存在，不计通过。原夹具未发送进程退出报告：页面明确提示“本机已断开，远端状态未确认”，可以返回，首页不出现成功提示。

对照夹具仅在临时副本中增加退出状态报告；相同流程收到远端退出报告后显示“已断开连接”，返回首页后出现成功提示。未返回退出报告不等于服务器仍在运行，也不代表输入已被远端执行。隔离夹具观察到密码认证与 PTY；没有访问真实服务器，没有重放远端输入。另以测试替身覆盖超时、无退出报告、退出报告和 980→390 缩窄后系统返回。
