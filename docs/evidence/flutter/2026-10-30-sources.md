## 字体比较仍有未消除条件

共享 JetBrainsMono Nerd Font Mono TTF 与 SHA 相同，只保证首选字体文件相同。当前 Flutter 使用 `TerminalStyle` 0.5.0 的默认 fallback 链（含 Roboto Mono、Menlo、Consolas、Noto Sans Mono CJK 各区域、Noto Color Emoji 等）；Tauri 路线的 CSS `monospace` 由 WebView/系统解析。**实际 CJK fallback 字体名称、emoji 来源与命中字形目前未识别，因此完整字体公平性与列宽正确性均未验证**。真机记录应包含实际命中的 CJK/emoji 字体或明确无法识别，不得只凭首选 TTF 的相同 hash 判通过。后续若加入共同 CJK/emoji 字体，须两路线同步固定文件、哈希与许可，再重跑同一 fixture。

## 组合字符缺陷定位（待云端最小复现）

Mac 真实 GUI smoke 使用 c8d70ab 产物、共享字体/fixture，观察到 Marks 的分解重音不可见；原生剪贴板因自动化桥无法可靠读取而未验证。2026-10-30 再次 Context7 `library terminal_view` 无对应条目，未将 Windows Terminal 等不相关结果冒充文档。继续检查已经 SHA256 核实的 pub 0.5.0 archive：

- `lib/src/core/buffer/buffer.dart:157` 对 `wcwidth == 0` 调用 `_appendToPreviousCell`；后者在第 186 行后存入 `line.setCombined`。
- `lib/src/core/buffer/line.dart:392` 的 `getText` 同时附加 base codepoint 与 `_combined`，不会主动归一化分解重音。
- `lib/src/ui/painter.dart:317` 起的 `_paintLineForeground`：ASCII 基字符进入批处理，内部只将 `getContent & codepointMask` 放入 runBuffer，没有检查 combined。只有后续非 ASCII 单 cell 路径传入 `combined: line.getCombined(i)`。

新增 `diagnostic/combining_render_test.dart`，独立 CI job 保留真实 Terminal buffer / painter 的输入、复制 API 输出、列宽与 PNG/RGBA 对照，若两幅像素完全相同则真实标记失败，不以 continue-on-error 掩盖。该诊断不经过本项目 GUI 数据接线，可区分上游 renderer 与壳输入路径；运行结果取得前仅记录源码定位与 Mac 目视事实。补丁需要让带组合字符的 ASCII cell 退出批处理，并处理批处理中遇到 combined 的截断、光标反色覆盖和缓存失效回归，当前没有修改上游。

## 已确证：ASCII 组合重音渲染失败

[真实诊断 job](https://github.com/Luck9Star/herdr-pocket/actions/runs/40985723032/job/123836544791)，源码 `ed35d84046c269169f1b72176ab769b398e6cca5`，在完成分析与既有6测试后独立执行，结论为 **failure**（期望像素不同，实际完全相同）。[保存的原始报告](combining-ed35d84/combining-render.json)显示：

- 输入与 `BufferLine.getText()` 都是 `U+0065 U+0301 U+0020 U+0041 U+030A U+0020 U+006E U+0303`，buffer 正确保留分解组合字符，光标列 `5`。
- 基字符 `e A n` 与分解重音 `é Å ñ` 的真实 painter 图像完全相同，均有 138 个非透明像素（排除全空图）。PNG SHA256 均为 `0faf2a8446a0c0b62d0f4442048367910242f99f14c06aa5b22ca1f42ff74cd7`。
- 图像已人工查看：显示基字符、没有重音。与 Mac 原生观察及已定位的 ASCII batch 忽略 combined 路径吻合，因此该候选版本的此项**渲染正确性失败**，不是未验证，也不是本壳输入转码问题。
- 不推断原生剪贴板数据丢失；复制 API 保留数据与系统 clipboard 实测是不同层。未修改/替换引擎，不因构建成功解除正确性阻断。
