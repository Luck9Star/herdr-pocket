## 首次 CI 失败与修复

[run 40982357582](https://github.com/Luck9Star/herdr-pocket/actions/runs/40982357582)，源提交 `c33cb573f56cc091082eeb46711e986a2344c2ae`：Flutter 3.47.9 / Dart 3.13.7 安装与隔离工程生成成功；依赖步骤 exit 65，analyze/test 与平台 build 未执行。原因是 `flutter create --no-pub` 仍复制模板 lock，脚本误把它当验证壳 lock 并 enforce。修复仅删除新生成的临时模板 lock；仓库有显式 lock 时仍原样复制并 enforce。首次上传的 lock 属模板，不作为应用有效锁落库。修复后的结果必须看新 run。

## 字体比较仍有未消除条件

共享 JetBrainsMono Nerd Font Mono TTF 与 SHA 相同，只保证首选字体文件相同。当前 Flutter 使用 `TerminalStyle` 0.5.0 的默认 fallback 链（含 Roboto Mono、Menlo、Consolas、Noto Sans Mono CJK 各区域、Noto Color Emoji 等）；Tauri 路线的 CSS `monospace` 由 WebView/系统解析。**实际 CJK fallback 字体名称、emoji 来源与命中字形目前未识别，因此完整字体公平性与列宽正确性均未验证**。真机记录应包含实际命中的 CJK/emoji 字体或明确无法识别，不得只凭首选 TTF 的相同 hash 判通过。后续若加入共同 CJK/emoji 字体，须两路线同步固定文件、哈希与许可，再重跑同一 fixture。
