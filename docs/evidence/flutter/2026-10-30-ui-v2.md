# Flutter v2 视觉接线与验证

2026-10-30。此记录描述离线验证壳的视觉适配，不表示真实 SSH、扫码或组网闭环已经实现，也不决定最终 UI 框架。

## 来源和实现

- 视觉颜色从共享 `validation/shared/design-tokens-v2.json` 运行时读取；原靛蓝操作色和深色终端保留，状态提示使用单独的深色文字变体。16 色 ANSI 是两壳共用的工程比较基线，与 Penpot 的实际 token 导出分开记录。
- Flutter 保持 3.47.9 / `c197ca5199e9ee5661e865596c9c07294dfab51c`；默认终端仍为官方未修改的 `terminal_view 0.5.0`。用户测试应选择 `flutter-candidate-*` 包，候选材料化及补丁 hash 仍按原修复工作流验证。
- 2026-10-30 使用 Context7 `library Flutter`，随后 `docs /flutter/website` 查询语义色、Material ThemeData/ColorScheme、焦点和响应式布局；参考 [Material 3 迁移文档](https://github.com/flutter/website/blob/main/sites/docs/src/content/release/breaking-changes/material-3-migration.md) 与 [Material 3 默认行为](https://github.com/flutter/website/blob/main/sites/docs/src/content/release/breaking-changes/material-3-default.md)。依赖没有升级。
- 固定 fixture、Nerd Font 文件、14px、80×24 与有界输入／输出不变。布局缩窄或键盘占用时允许本地工作区滚动，不发送远端 resize；隐藏标签必须重新获取 full。桌面分屏阈值仍为 960px，Tauri 为 900px；390/1440 对照视口不受该阈值差异影响。
