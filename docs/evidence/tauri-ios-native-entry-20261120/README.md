# Tauri iOS 原生入口验收 R2

官方 Actions 脱敏产物；源码 `c5aa64a0c9703d0494f5694ec0028018f7f2a0b8`。测试为 iOS 26.2 模拟器中的真实 Tauri 应用、XCTest 原生交互和隔离回环 SSH 对端，并非物理 iPhone 或公网 SSH 验收。压缩包保留服务端已脱敏 `result.json`，普通及换钥包另含公开截图与 OCR 结果；不包含原始 XCTest/AX 日志或凭据。

| 44583882651 | 14562341236 | 普通密码、换钥通过。两次首页与选择各一次点击进入；六个目标字段首次读回匹配。 |
| 44583969020 | 14559684499 | 加密私钥手输未通过：到达错误 PEM 核验后，口令阶段 `native_secret_exposed`；触发节点未分类，不能推断真实泄露或误报。 |

普通连接两条 peer 记录：首条认证前关闭，第二条认证一次成功、请求一次 PTY 和 shell、精确收到单条标记并断开。键盘开合及看板、网络、设置往返时保持同一活动 peer，未输入额外数据。换钥四条 peer 记录：初探、拒绝更换、重新探测均无认证；取消保留原信任，重新确认后第四条认证一次并完成终端和断开。手输失败时仅有一次探测连接、零认证，清理后关闭。两案首页和选择的原生点击框分别为 `[40,294,360,48]`、`[24,186,392,100]`。

与 R1 比较：手输 R1 首页出现 `[17,166,163,22]` 后无进展；普通 R1 在 `ordinary_host` 输入读取处失败。R2 这两个断点均未复现；现场未证明 R1 的原因。R2 输入读回采用同一归属字段的只读重采样，所有成功字段第一次即匹配，不能据此证明延迟读取是 R1 根因。

校验：在本目录执行 `shasum -a 256 -c SHA256SUMS`。包内 `result.json` 提供逐阶段动作、peer、清理、设备和源绑定信息；成功包中截图/OCR 的哈希也可与该 JSON 核对。`metadata.json` 记录公开作业及 artifact 标识。
