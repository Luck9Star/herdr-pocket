## 网络目录的三种结果

沿用现有只读 `network_list`：只有返回非空版本标识、有效终端字号、空 profiles 和空 bindings 时，活动普通 SSH 的桌面网络页才展示空卡。三个桌面宽的卡片及添加按钮与冻结稿的对应矩形差 0：1440/980 为 `[264,144,560,204]` 和 `[280,284,528,48]`，700 为 `[104,144,556,204]` 和 `[120,284,524,48]`。真实“添加网络配置”按钮进入现有新增表单；额外保留“管理网络与共享设备”入口，确保共享设备审查仍可达。脚本实际点击新建、取消、管理，以及关闭和重新打开面板，并确认没有调用配置保存。

`980x780-configured` 使用一条合成配置，验证原管理列表和新增入口仍可用；`980x780-unavailable` 模拟读取失败，验证显示未知提示而不显示空卡。单元测试还覆盖读取中、关闭后迟到返回、缺失或无效元数据、悬空绑定，以及连接状态切换时不覆盖编辑草稿。网络数据均为受控 fixture，本批未读取或改变用户的真实网络配置。

## 复验

从仓库根目录执行，先确保 Tauri `dist` 与当前源码一致。只需临时安装 Playwright 和复制虚构的主机公钥，无需私钥：

```sh
PRODUCT_DIST="$(pwd)/validation/tauri/dist"
EVIDENCE_DIR="$(pwd)/docs/evidence/tauri-ordinary-terminal-layout-20261120"
REPLAY_DIR="$(mktemp -d)"
mkdir -p "$REPLAY_DIR/fixture"
cp "$EVIDENCE_DIR/replay.mjs" "$REPLAY_DIR/"
cp "$EVIDENCE_DIR/fixture/host.pub" "$REPLAY_DIR/fixture/"
cd "$REPLAY_DIR"
npm install --no-save playwright@1.62.1
npx playwright install webkit
FEEDBACK_PRODUCT_DIST="$PRODUCT_DIST" FEEDBACK_EVIDENCE=output node replay.mjs
```

脚本运行三个桌面、两个移动、长目标、合成已存主机以及网络已有配置/读取失败共九个场景。它不访问真实 SSH 授权文件、网络身份或私钥。
