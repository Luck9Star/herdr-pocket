## 文档核实

- `library 'Tauri' 'Tauri 2 minimal cross-platform application with Rust commands Channel binary data bounded flow control and Android iOS CI build syntax; use xterm.js terminal frontend without remote command execution'` → `/tauri-apps/tauri-docs` → 同问题 docs。
- `library 'xterm.js' 'Use xterm.js 6 terminal input onData IME composition paste interception write callback flow control focus change tabs and fixed terminal cols rows without remote resize'` → `/websites/xtermjs` → 同问题 docs。

关键来源：[Tauri Channel](https://v2.tauri.app/develop/calling-frontend/#channels)、[xterm flow control](https://xtermjs.org/docs/guides/flowcontrol/)。本项目只在 xterm write 回调后回收信用额度。固定 CLI `2.12.4` 的本地 `ios build --help` 实际列出 `--no-sign`、`--archive-only`，比当前 Context7 索引更完整；采用 CLI 实际参数，不据旧索引编造签名能力。
