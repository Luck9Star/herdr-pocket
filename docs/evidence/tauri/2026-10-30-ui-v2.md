## 实现与来源

- `validation/shared/design-tokens-v2.json` 由 Penpot 设计流读回语义色；`theme.js` 映射应用 CSS 变量和 xterm 主题。操作/焦点使用 Tech Indigo，暗色终端与独立状态色保持用户认可的视觉方向。
- 两壳显式共用 16 色 ANSI 调色板和选择高亮 alpha `0x55`。16 色来源是固定 terminal_view 默认值的工程比较基线，并非 Penpot 导出值；本轮不修改 fixture 原始 ANSI/Unicode 字节、字体或 80×24 字符格。
- 新增侧栏、分段模式按钮、未知结果说明与顺序恢复动作。缩小窗口只改变本地可滚动区域，未引入 fit addon、终端 resize 或输入重放。
- 将离线验证工具移入默认折叠区域；网络标签明确为示例路径，没有显示伪造的真实在线状态。

API 查询：按 AGENTS 先运行 Context7 `library xterm.js`。首次出现 `fetch failed`，无沙箱限制下重试解析到 `/xtermjs/xterm.js`；文档确认 `theme` 为可配置选项、`cols/rows` 为初始化尺寸，FitAddon 会调用 resize。实际实现同时核对锁定 `@xterm/xterm 6.0.0` 的随包 `typings/xterm.d.ts`，仅使用公开主题字段，未安装/升级依赖。
